# rFkUnCK_you

Локальное приложение Kaev для Telegram Desktop и Discord на сетях с блокировками. Первая публичная бета — Telegram Desktop на Windows x64. Discord — следующий релиз. Linux и macOS рассматриваем после Windows. Свой VPN-сервис — отдельный проект.

## Архитектура

- C# / .NET 10 LTS, Avalonia для окна. Начинаем с консольного прогона. Интерфейс вызывает управление компонентами и получает их статусы. Системные операции остаются вне окна.
- У Telegram и Discord независимые процессы. Запускай и останавливай экземпляры, которыми управляет приложение. Различай запуск процесса, готовность компонента и проверку сервиса.
- Фиксируй проверенные версии внешних компонентов. Храни локальные артефакты и секреты вне Git. Исключай ключи и ссылки с ключами из журналов.

## Референсы и лицензия

- [Slipgate](https://github.com/tenstepsbeforedecay/Slipgate) даёт идею одного окна и независимого управления компонентами. Реализуем собственные код и интерфейс. Для беты достаточно одного локального прокси и понятной диагностики.
- [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) запускаем как отдельный процесс через upstream CLI. В отладке используем Python-окружение, в релизе упаковываем CLI для Windows.
- [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) — кандидат для Discord. Проверяем запуск стратегии, получение статуса WinDivert и остановку своего winws. Повышенные права относятся к этому режиму.
- Свой код — GNU GPL v3.0. Для каждого включённого стороннего компонента проверяй лицензию версии и вложенных файлов. Сохраняй обязательные уведомления и выполняй условия предоставления исходников.

## Порядок работ

1. Прогнать TG WS Proxy без GUI на текущем ПК. Проверить запуск, занятый порт, остановку и повторный старт. Пользователь проверяет сообщения и медиа в Telegram Desktop до и после подключения. Записать версию компонента и результат.
2. Реализовать управление прокси в .NET. В окне Avalonia показать запуск, остановку, «Открыть в Telegram» и понятные ошибки. Проверить выход приложения и падение процесса.
3. Упаковать Telegram-бету для Windows x64, проверить на чистой Windows и опубликовать соответствующие исходники и лицензии.
4. Прогнать Zapret из консоли. Проверить текст и голос Discord, отказ в повышении прав и остановку своего процесса. После этого добавить режим Discord в приложение.
5. Проверить Linux и macOS отдельно для каждого компонента. Порты объявляем после реальных проверок.
